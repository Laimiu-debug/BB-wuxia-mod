# BB-wuxia-mod

《战场兄弟》（Battle Brothers）武侠 Mod。当前为基于 Modern Hooks 的 `v0.7.2` 公测试玩版。

## 当前进度

- **M0 开局与存档**。Windows 版 Battle Brothers 1.5.2.3 冷启动通过全量 `AfterHooks` 引擎自测（18 大项全系统自动化断言）。实装 **6 大纯正武侠起源**（「初走江湖 · 威远散镖队」「孤剑独行 · 天涯浪客」「少室下山 · 护法行者」「百草毒医 · 南疆采药行」「边关残部 · 铁血老卒」「演武试剑台」），隐藏西式旧起源并完整兼容旧档。
- **M1 武学培养、战团藏经阁与出身武侠化**。实装 7 槽经脉盘（7 级外功/横练杂学双选槽 + 限 2 内 2 轻）、先学后配保留重数火候、散功调息、灵丹/内丹灌注、残本强修、3/5 页拼合与洗经伐髓；新增零占格**「藏经阁」**、**「残页参悟化功」**（享同脉 `+25%` / 同名 `+50%` 共鸣）与**「同阶残页 2:1 融会补缺」**。保留原版 Background ID 原地映射 **72 条江湖出身 + 500 篇独立人物列传**，入队按身价自动预装 `0 / 1 / 2` 本契合兵器的入门功法。
- **M2 战斗、防膨胀与演武特效**。外功面板与全部 **50+ 项正交组合机制词条**严格执行 `Math.max` 防累加红线；轻装叠乘减伤 `60%` 封顶，重甲横练线内置披甲行气/沉岳硬抗/铜头铁额；常驻 AP 硬封顶 `11`，燃血/首杀短时升至 `12~13`。实装 **72 式零重复四帧招式动作序列（288 帧）+ 32 款气芒 + 16 款法相阵印 + 16 款独立武侠飞行投射物**。
- **M3 九州门派、江湖志向与委托净化**。实装 **44 大地域门派**（茶楼按地貌刷出 3 席门派任选 + 九州名刺录跨界面检视 + 交恶寻仇队）、**66+7 个原创江湖与山海奇遇**，并完成全 **50 类城镇/藩镇/西域委托**、**48 项江湖志向（Ambitions）**、藩镇节度使/丝路都护府势力及纹银/修械铁料/行军粮秣的全面武侠化重塑。
- **M4.1–M4.2 《山海经》六十四大妖秘境与藏经阁 272 秘籍**：
  - **272 本武学秘籍**（覆盖刀、剑、枪、长兵、成对护手拳掌、重锤、大斧、软鞭连枷、短匕、弓弩、暗器、神机火器、藤牌铁盾全 13 类兵装）；
  - **64 尊《山海经》凶兽·大妖·古神战魂首领与动态轮替秘境** + 四大武林禁地 + 天下武林大会 + 子夜无常鬼市，配套「老猎妖师·山海异兽图志」探明迷雾。
- **M4.4–M4.6 双轨炼丹（百草药柜 · 八卦丹炉 · 31 灵丹）与猎妖百工重锻（59 神兵 · 40 宝甲冠盾奇佩 · 16 百工奇物）**：
  - **零占格「百草药柜」+ 随身「八卦丹炉」**：自动收纳 **17 味《山海本草》奇草**与 **96 种山海内丹**（兼容异兽奇材入柜与城镇丹坊跨柜直炼），支持六脉药性君臣配伍、智能抓药、**28 道丹炉方**、**31 种灵丹**、**三阶成丹品相（`成丹 / 灵纹 / 丹霞`）**与六脉**「药引丹韵」**功效分化（含《生生造化丹》《黑玉断续膏》《太乙紫金洗髓丹》《易筋锻骨丸》《忘尘归元散》及山海对策备战丹，严守单场 2 颗安全上限与 `+25%` 穿甲封顶）；
  - **百工铸兵、山海神通与免内丹「神兵重锻」**：实装 **6 种手绘异兽奇材**、**16 件前中期【百工奇物】兵甲镶件**、**59 把历史传世与山海神兵**、**40 件山海宝甲/宝冠/传世神盾/异宝佩饰**及 **50 项【山海神通 / 百工兽魄】**轻机制词条；全兵甲支持 **`凡锻 / 良工 / 百炼 / 神工` 四阶品相与属性浮动区间预览**，随身与丹坊内置免大妖内丹**「神兵重锻」**工作台与五锤百炼炉温保底。
- **国风全局 UI 与交响民乐 OST**：实装明代乌木宣纸青铜全局皮肤、千人千面 8 层纸娃娃（铜镜易容、4 色须发、16 款背负兵匣披风、战损尸骸与大地图领队半身像）、中式州府山门与十四坊铺、竖幅战旗及 **18 首纯器乐国风交响/民乐 OST**。根目录 [山海武侠.html](山海武侠.html) 提供完整交互百科与演武工坊。

正式开局的实机回归已从第 1 天推进到第 61 天。12 名队员在册，五派都曾出动寻仇队，逐日检查未出现同派重复出队。两处据点的战利品、撤退守军人数和胜利后的读档状态均已核对。回归使用加速时钟、预配武学与测试资金，自然游玩的成长、收支和首领难度仍待评估。

## 本地构建

```bash
python tools/build_mod.py
```

脚本静态检查 Squirrel 和 JavaScript，并生成 `dist/mod_wuxia.zip`。安装时，将 MOD 放入已装 Modern Hooks 的游戏 `data/` 目录。
