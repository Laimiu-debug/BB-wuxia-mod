# BB-wuxia-mod

《战场兄弟》（Battle Brothers）武侠 Mod。当前为基于 Modern Hooks 的 `v0.8.8` 正式打包版（`dist/mod_wuxia-0.8.8.zip`）。启用「炽热沙漠」DLC 时，新战役使用 `140 × 170` 格九州西域超大世界地图。

## 本地构建与发布打包

```bash
# 开发包（开启冷启动 SelfTest 断言日志）
python tools/build_mod.py

# 正式发布包（关闭 Debug/SelfTest，同时输出 dist/mod_wuxia.zip 与 dist/mod_wuxia-0.8.8.zip）
python tools/build_mod.py --release
```

脚本静态检查全部 Squirrel（`.nut`）、ES3 JavaScript（`.js`）与样式表（`.css`），并生成可直接放入已安装 Modern Hooks 的游戏 `data/` 目录的压缩包。
