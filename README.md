# BB-wuxia-mod

《战场兄弟》（Battle Brothers）武侠 Mod 的设计仓库。当前处于**设计阶段**，尚未开始正式代码实现。

## 仓库里有什么

### 三份 HTML（设计浏览工具）

| 文件 | 说明 |
| --- | --- |
| `武侠百科.html` | 自包含武侠设计百科：原版词条到武侠命名的映射、系统与词条、设计议题与推演 |
| `jianghu-systems.html` | 「一局江湖的系统关系」交互图：模块因果与药镖推演 |
| `bbmod-wiki.html` | BBMOD 原版百科首页快照，作对照入口 |

浏览器直接打开即可阅读，不依赖构建。

### `docs/`（方案与评审）

| 文件 | 说明 |
| --- | --- |
| [docs/wuxia-mod-design.md](docs/wuxia-mod-design.md) | 整体设计方案 |
| [docs/wuxia-outline-reconciliation.md](docs/wuxia-outline-reconciliation.md) | 六模块大纲与方案的对照 |
| [docs/repo-review.md](docs/repo-review.md) | 对本仓库现状的评审 |
