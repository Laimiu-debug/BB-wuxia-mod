# BB-wuxia-mod

《战场兄弟》（Battle Brothers）武侠 Mod。当前为基于 Modern Hooks 的 `v0.5.0` 开发版。

## 当前进度

- **M0 开局与存档**。Windows 版 Battle Brothers 1.5.2.3 冷启动通过全量 `AfterHooks` 引擎自测。「演武试剑台」和「初走江湖」共用选址逻辑，正式开局生成 5 名带起始武学的同伴。
- **M1 武学培养与出身武侠化**。已验证 7 槽（7 级双选槽 + 限 2 内 2 轻）、散功、灌注、残本、拼合和洗髓；新增**「残页参悟化功」（闲置残页拖入未满重槽位化为火候，享同脉 +25% / 同名 +50% 共鸣）与「同阶残页 2:1 融会补缺」**双出口，并升级行囊**「适配当前兵器 + 关键词实时检索」**。保留原版 Background ID 原地武侠映射 72 条出身（完整兼容原版 300+ 随机事件），入队按身价自动预装 `0 / 1 / 2` 本入门功法。
- **M2 战斗与防膨胀**。外功面板与全部 **50+ 项正交组合机制词条**全面启用 `Math.max` 防累加红线；轻装叠乘减伤 60% 封顶，重甲横练线内置披甲行气/沉岳硬抗/铜头铁额。调息每回合限用一次，常驻 AP 上限 11，燃血/首杀可短时升至 12~13。
- **M3 江湖、掉落与传世历史神兵**。交恶门派各自派人追缉；实装 **37 把历史与古典传世名兵红武**（如`太阿古剑`、`七星龙渊剑`、`巨阙至尊大剑`、`大唐嗣业斩马陌刀`、`沥泉盘龙神枪`、`温侯方天画戟`、`青龙冷艳锯`、`紧那罗混铁盘龙棍`、`天下丐帮绿玉竹杖`、`专诸鱼肠短剑`、`擂鼓瓮金巨锤`、`薛家震天铁胎神弓`、`赵氏神机五雷连铳`等，100% 接入原版 `named_weapon` 红装随机词条并预留独立美术替换配置），投放于四大据点禁地宝箱、无常鬼市压轴竞拍、武林大会魁首与铁匠铺奇遇。
- **M4.1 藏经阁大扩建（264 本武学秘籍）与 44 大地域江湖门派专属传承**：
  - **264 本非换皮组合机制秘籍 + 32 个武学主动招式**：覆盖全 13 类兵器与内/外/轻/横四脉（含穿云透甲刺、八方狂澜斩、百鸟朝凤击退刺、横扫千军、擒龙探爪拉人、裂地崩山锤、旋风断魂斧、锁喉缠丝封穴、分水断脉刺、流星追月箭、漫天花雨、铁壁震山靠等），全量通过 `AGENTS.md` 面板上限与词条白名单校验；
  - **44 大门派全员专属藏书架**：每家门派拥有 **5~11 本**符合门风地域的独门传承，茶楼门派事件升级为**「按地貌刷出 3 席门派任选 + 单席 3 本秘籍同台请教」**。
- **M4.2 「低魔志怪武侠」生态、百工丹方与终极挑战**：
  - **全图阵营与异兽同构映射**：大地图与战术内 **70+ 类单位**与 **22 种异兽战利品**原地映射为绿林马贼、藩镇官军、五毒奇门、关外战帮/邪派药人、前朝古墓机关人/湘西尸傀与山泽异兽；古墓机关与湘西尸傀免疫点穴封气与暗器奇毒；
  - **百工炼丹与终极考验**：剥制师共 3 张异兽炼丹配方（洗髓丹、凝神丸×2、护脉丹+护心丹）；4 处秘境据点（含`前朝玄宫秘冢`、`五毒炼药魔窟`两大武林禁地）、4 大**武林大势**后期危机同步与终极演武事件**「天下武林大会」**。

正式开局的实机回归已从第 1 天推进到第 61 天。12 名队员在册，五派都曾出动寻仇队，逐日检查未出现同派重复出队。两处据点的战利品、撤退守军人数和胜利后的读档状态均已核对。回归使用加速时钟、预配武学与测试资金，自然游玩的成长、收支和首领难度仍待评估。

## 本地构建

```bash
python tools/build_mod.py
```

脚本静态检查 Squirrel 和 JavaScript，并生成 `dist/mod_wuxia.zip`。安装时，将 MOD 放入已装 Modern Hooks 的游戏 `data/` 目录。
