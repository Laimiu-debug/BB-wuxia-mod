# BB-wuxia-mod

《战场兄弟》（Battle Brothers）武侠 Mod。当前为基于 Modern Hooks 的 `v0.4.0` 开发版。

## 当前进度

- **M0 开局与存档**。Windows 版 Battle Brothers 1.5.2.3 冷启动通过 **47 项 `AfterHooks` 引擎自测（47/47 PASS, 0 ERROR）**。「演武试剑台」和「初走江湖」共用选址逻辑，正式开局生成 5 名带起始武学的同伴。
- **M1 武学培养与出身武侠化**。已验证 7 槽（7 级双选槽 + 限 2 内 2 轻）、散功、灌注、残本、拼合和洗髓。**保留原版 Background ID 原地武侠映射 72 条出身**（完整兼容原版 300+ 随机事件），城镇招募入队按身价档位自动预装 `0 / 1 / 2` 本对应一重入门功法。
- **M2 战斗与防膨胀**。外功面板与同系词条全面启用 `Math.max` 防累加红线；轻装叠乘减伤 60% 封顶，《铁布衫》内置披甲行气/沉岳硬抗/铜头铁额。调息每回合限用一次，常驻 AP 上限 11，燃血可短时升至 13。
- **M3 江湖与掉落**。交恶门派各自派人追缉；血煞总寨与叛门剑首据点攻克可得残页与洗髓血芝；鬼市拍卖可竞拍洗髓丹、绝学、孤本及**传世红武拳套**。
- **M4.1 全兵器武学闭环与 44 大地域江湖门派网络**（现共 **46 本秘籍、44 个江湖门派/世家/堂口**）：
  - **全兵器全覆盖**：剑、刀、枪长柄、棍棒、成对拳掌护手（含原生随机红武）、重锤（震岳碎甲）、大斧（力劈碎盾）、软鞭连枷（云梦绕盾爆头）、短匕分水刺（借绽透骨处决）、弓、强弩、暗器、神机火铳全 13 类兵器均有对应武学与招式；
  - **44 大门派与六大地域茶楼三席择派**：14 大核心宗门 + 30 方地域世家/镖局/帮会/绿林邪道（按中原官道、名山险岳、巴蜀密林、江淮水泽、关外北境、西域大漠驻扎），零真势力 ID 消耗；升级城中茶楼事件为**「按地貌同时刷出 3 席门派任选 + 双秘籍展示 + 宴请交情」**，彻底杜绝多门派随机稀释。
- **M4.2 「低魔志怪武侠」生态、百工丹方与终极挑战**：
  - **全图阵营与异兽同构映射**：大地图与战术内 **70+ 类单位**与 **22 种异兽战利品**原地映射为绿林马贼、藩镇官军、五毒奇门、关外战帮/邪派药人、前朝古墓机关人/湘西尸傀与山泽异兽；古墓机关与湘西尸傀免疫点穴封气与暗器奇毒；
  - **百工炼丹与终极考验**：剥制师共 3 张异兽炼丹配方（洗髓丹、凝神丸×2、护脉丹+护心丹）；4 处秘境据点（含`前朝玄宫秘冢`、`五毒炼药魔窟`两大武林禁地）、4 大**武林大势**后期危机同步与终极演武事件**「天下武林大会」**。

正式开局的实机回归已从第 1 天推进到第 61 天。12 名队员在册，五派都曾出动寻仇队，逐日检查未出现同派重复出队。两处据点的战利品、撤退守军人数和胜利后的读档状态均已核对。回归使用加速时钟、预配武学与测试资金，自然游玩的成长、收支和首领难度仍待评估。

## 本地构建

```bash
python tools/build_mod.py
```

脚本静态检查 Squirrel 和 JavaScript，并生成 `dist/mod_wuxia.zip`。安装时，将 MOD 放入已装 Modern Hooks 的游戏 `data/` 目录。
