# BB-wuxia-mod

《战场兄弟》（Battle Brothers）武侠 Mod。当前版本为 `v0.8.22`（`dist/mod_wuxia-0.8.22.zip`），依赖 Modern Hooks。启用「炽热沙漠」DLC 时，新战役使用 `140 × 170` 格九州西域超大世界地图。

## 当前实装系统总览（v0.8.22）

- **v0.8.22 战斗回合与地图道路**。双格异兽在等待或回合结束时流血身亡，回合栏会跳过随本体消失的部位。换轮或战斗结束时会清除旧头像的动画。暗器剧毒在等待或回合结束时每轮结算一次，免疫流血的目标不再被武学附加流血。补齐了地图上四个斜向道路尽头的贴图。

- **v0.8.21 地阵识别盟军**。唐门机簧按战斗中的实际敌我关系触发。与佣兵并肩作战的其他势力也能获得太极两仪域的友军加成。

- **v0.8.20 药人窟火并与野战进场修复**。药人窟委托触发两帮火并时，战场和战报用「守寨」与「攻寨」标明双方。修复野外遭遇中敌对阵营编号达到 32 时，点击准备战斗卡在加载画面的问题。

- **v0.8.19 地图、战斗与界面修复**。新战役恢复原版野外传奇地点并缩短建图时间，旧档可在读档时补建。修复野外队伍误标参战、跨档残留门派追踪、擂台退出报错，以及工坊余额、重锻完美度、灌注火候与洗髓星级显示。减少战斗中特效图集的重复加载，修正苍龙雷泽套和大荒金乌套的命中特效引用。贵族战争 20 对 20 的敌方回合停滞仍在排查。

- **v0.8.18 战斗回合与备战修复**。双格蛟兽的本体或尾部在等待时流血身亡后，回合栏会跳过两个死亡部位，让下一名角色行动。如果它是最后一个敌人，战斗正常结算。从主菜单进入独立战斗时，角色备战界面也能在没有战团仓库的情况下打开。

- **v0.8.17 战斗与炼丹修复**。修正山海异兽选敌、图腾射线、部位属性和破部位掉落。战场剑影、陷阱及限时地形按轮生效。本命丹方接受指定内丹，战中药散正确扣剂、施毒并累计丹毒。武学连招按段耗气，命中附效每次出招只结算一次。

- **v0.8.16 战术 AI 升级、武侠音效、奇经特质、配槽预设与性能精修**。修复动态敌军内轻功上限检定并实装 12 流派连招/抗性选敌 AI；新增 18 项兵家真气战斗音效与 6 项突破炼丹淬火仪式音效；原地武侠化 58 项原版特质并新增 10 项先天奇经异脉特质（联动洗髓、火候、剑招省气与丹毒豁免）；角色面板支持 3 套功法配槽预设（兼容忘尘归元散无损切换）与全局「机枢」设置，战斗底栏支持滚轮/快捷键翻页与 `AP·内息` 双微标；实装团战阵眼光环纪元缓存、悬停文本词典缓存及 17 MB 图集无损瘦身，并补齐《山门血书求援》与《篝火夜话传功》奇遇事件。

- **v0.8.15 孤剑独行开局**。新战役以一名 5 级剑客开局，随机获得两项正面特质，武艺和另外两项属性各有二至三星根骨。剑客随机走轻装单手剑或披甲双手剑路线。初始四槽装配一门绝学和三门上乘武学，其中两门已达二重，另备一门未装配的上乘武学。

- **v0.8.14 战团志向与百工进度**。城镇百工丹坊与八卦丹炉合计制作三次即可完成百工志向。炼出灵纹或丹霞品相的丹药可完成上品丹志向，旧存档行囊中的上品丹也可认定。行囊拼书、洗髓升星和山海首领击杀会记录进度。三星根骨志向只需一项属性达到三星，洗髓志向在行囊已满时将赠丹折银。

- **v0.8.13 拳鞭平衡与战斗演出**。调整拳套伤害、穿甲和拳招消耗，修正鞭枷绕盾与流血、远程敌人选位和火铳装填。定向特效随出招方向镜像，招式特写与屏幕压暗可在选项中开启。战后头像恢复原位，倒地外观沿用角色的衣甲和冠发。

- **v0.8.12 招式演出、人物装束与战团志向**。171 个主动招式新增逐帧演出与战场题字。调整了冠帽、发型和护甲的叠放，物品提示按品级和用途着色。掌旗官及兵器专精志向可按武侠功法判定达成。

- **v0.8.11 百工丹坊与易容阁**。炼丹、铸器和重锻会在点击后立即开始演出，丹方列表复用药材统计。易容阁可在镜中切换摘帽、戴帽预览。宗门往来、法帖交付和演武兑票新增结算展示。

- **v0.8.10 宗门试炼、分档药庐与成果展示**。闯护山大阵时，双方受致命一击会认负退场。生死踢馆沿用实战规则。山门药庐按门派供应常备灵草和镇庐珍株，两档各有交情门槛、售价与冷却。炼丹、铸造、武学修习与洗髓等操作新增成果展示，可跳过演出或启用快速模式。

## 本地构建与发布打包

```bash
# 开发包（开启冷启动 SelfTest 断言日志）
python tools/build_mod.py

# 正式发布包（关闭 Debug/SelfTest，同时输出 dist/mod_wuxia.zip 与 dist/mod_wuxia-0.8.22.zip）
python tools/build_mod.py --release
```

脚本静态检查全部 Squirrel（`.nut`）、ES3 JavaScript（`.js`）与样式表（`.css`），并生成可直接放入已安装 Modern Hooks 的游戏 `data/` 目录的压缩包。
