# BB-wuxia-mod

《战场兄弟》（Battle Brothers）武侠 Mod。当前为基于 Modern Hooks 的 `v0.3.0` 开发版。

## 当前进度

- **M0 开局与存档**。Windows 版 Battle Brothers 1.5.2.3 冷启动通过 **42 项 `AfterHooks` 引擎自测（42/42 PASS, 0 ERROR）**。「演武试剑台」和「初走江湖」共用选址逻辑，正式开局生成 5 名带起始武学的同伴。
- **M1 武学培养与出身武侠化**。已验证 7 槽（7 级双选槽 + 限 2 内 2 轻）、散功、灌注、残本、拼合和洗髓。**保留原版 Background ID 原地武侠映射 72 条出身**（完整兼容原版 300+ 随机事件），城镇招募入队按身价档位自动预装 `0 / 1 / 2` 本对应一重入门功法。
- **M2 战斗与防膨胀**。外功面板与同系词条全面启用 `Math.max` 防累加红线；轻装叠乘减伤 60% 封顶，《铁布衫》内置披甲行气/沉岳硬抗/铜头铁额。调息每回合限用一次，常驻 AP 上限 11，燃血可短时升至 13。
- **M3 江湖与掉落**。交恶门派各自派人追缉；血煞总寨（6 人）与叛门剑首据点（4 人）攻克可得残页与洗髓血芝；鬼市拍卖可竞拍洗髓丹、绝学、孤本及**传世红武拳套**。
- **M4.1 兵器、门派与拼图扩展**。新增成对占主副手双槽（4 AP 出招防配盾）的 `Fist` 护手武器线（`麻布缠手 → 精铁指虎 → 玄铁拳套 → 传世名器护手`），配套少室禅院掌指外功与团队拼图杂学（《缠字诀》《龟息护脉桩》《孤锋诀》《聚义令》《雁行掩射谱》《护阵棒法》）。
- **M4.2 「低魔志怪武侠」生态、百工丹方与终极挑战**（现共 **36 本秘籍、7 个轻量门派、4 处专属秘境据点**）：
  - **全图阵营与异兽同构映射**：零额外真势力 ID 消耗（稳守 `< 64` 红线），将大地图与战术内 **70+ 类单位**与 **22 种异兽战利品**原地映射为绿林马贼、藩镇官军、五毒奇门、关外战帮/邪派药人、前朝古墓机关人/湘西尸傀与山泽异兽（白猿、毒蛟、山魈、五毒巨蛛）；**古墓机关与湘西尸傀免疫点穴封气与暗器奇毒**。
  - **全阵营敌我同源掉落与新秘籍**：接入第 7 门派**五毒奇门**及《五毒吹影功》（见血淬毒/百毒不侵）、《血煞金钟罩》（横练绝学，反震敌甲）、《九幽镇魂录》（古墓镇魂孤本，慑魂动摇+破邪增伤），覆盖塞外、官军、战帮、药人、五毒、尸傀全生态精英武学挂载与掉落。
  - **百工炼丹与终极考验**：剥制师新增「凝神丸 ×2」与「护脉丹 + 护心丹」异兽炼丹配方；大世界新增两处**武林禁地**（`前朝玄宫秘冢`、`五毒炼药魔窟`，补齐全部 4 本孤本的稳定产出路径）、四大**武林大势**后期危机衔接及终极擂台事件**「天下武林大会」**。

正式开局的实机回归已从第 1 天推进到第 61 天。12 名队员在册，五派都曾出动寻仇队，逐日检查未出现同派重复出队。两处据点的战利品、撤退守军人数和胜利后的读档状态均已核对。回归使用加速时钟、预配武学与测试资金，自然游玩的成长、收支和首领难度仍待评估。

## 本地构建

```bash
python tools/build_mod.py
```

脚本静态检查 Squirrel 和 JavaScript，并生成 `dist/mod_wuxia.zip`。安装时，将 MOD 放入已装 Modern Hooks 的游戏 `data/` 目录。
