# 《战场兄弟》武侠 Mod 核心系统总设计

> **文档地位**：本项目当前的**唯一设计真相源（Single Source of Truth）**。  
> 早期探索稿（独立内力条、DPF 动态天赋树、架势条、后台自治药镖等旧口径）均已归档至 `docs/archive/`，仅供历史参考，不再作为现行规格。

---

## 0. 设计总纲与核心原则

1. **以人物培养为绝对核心，自底向上建构**：先锁死 BB 原版人物属性骨架，再围绕属性长出“插槽秘籍培养 → 战斗兵甲 → 江湖大世界与经济”四层闭环，绝不堆砌与核心循环脱节的悬浮系统。
2. **顺应 BB 引擎底层，不做反引擎魔改**：保留 BB 最经久不衰的八维数学、装备负重博弈、12 人群战与高风险高回报铁人感，将所有开发精力聚焦在**武学构筑多样性、秘籍/洗髓追逐感与江湖内容厚度**。
3. **无固定主角，谁都可以是主角**：沿用 BB 经典幕后掌门/领队视角，没有强制不可死亡的主角单位，人人皆可凭机缘与培养成为大哥，人人也皆可战死沙场。
4. **轻量稳健的技术底座**：因彻底取消传统 Perk 树，**不再强依赖 DPF 与 Nested Tooltips**；底层框架收敛为 **Modern Hooks + MSU**（要求全 DLC 以复用工艺、随从、竞技场等原版模块），数据结构与存档完全自主可控。

## 1. 第一层：人物属性底盘

核心思路：**不动 BB 原版核心八维的底层数学公式**，通过武侠化语义重塑与后续系统（武学、装备、丹药）读写这些数值。

### 1.1 核心八维（升级时照旧 8 选 3）

| 原版八维 | 武侠对应（暂定名） | 底层职责与关键联动 |
| --- | --- | --- |
| 生命值 (HP) | **气血** | 承受实伤、决定外伤触发阈值 |
| 疲劳值 (Fatigue) | **内息 / 内力** | **内力与疲劳合一（单资源池）**；移动、出招、内功护体均消耗此池；受衣甲负重直接压制上限 |
| 意志 (Resolve) | **定力 / 心志** | 战意检定、抗恐惧/震慑/心魔、影响高阶内功修炼与冲突抗性 |
| 先攻 (Initiative) | **身法** | 回合出手顺序；与轻功、闪避、先手压制深度联动；实时受负重与当前已耗内息影响 |
| 近战技能 (MAtk) | **武艺** | 近身出招命中率 |
| 远程技能 (RAtk) | **射艺 / 暗器** | 弓弩、飞镖、暗器命中率 |
| 近战防御 (MDef) | **招架** | 近身闪避与拆招防御 |
| 远程防御 (RDef) | **避暗** | 躲避箭矢与暗器 |

### 1.2 结构与战斗衍生属性

- **行动点 (AP)**：常人默认固定 **9 点**；**不再写死，但仅能通过特定武功秘籍（高阶/高重功法）突破**。数值上严控 9 → 10 → 11（及带代价的短时爆发）的质变阶梯，防止单回合无脑双大招击穿平衡。
- **头甲 / 身甲**：沿用原版护甲与穿甲底层机制，替换为武侠冠帽与衣甲，支撑“轻装 vs 重甲”双轨生存。
- **战意（原版士气 Morale）**：沿用原版 5 档状态（高昂 → 稳定 → 动摇 → 崩溃 → 溃逃），由定力驱动。
- **视野 (Vision) & 控制区 (ZoC)**：沿用原版底层机制。
- **移动消耗（地形、高低差、脱离 ZoC）**：**由轻功系统全面接管与改写**。

### 1.3 先天底盘与“洗经伐髓”

- **出身（原版 Background 原地武侠映射）**：**保留原版 Background ID 不删改**（确保原版 300+ 道路/营地随机事件全部正常触发），通过 Hook 映射为江湖行当与武林身份（如庄稼把式、走镖趟子手、行脚僧、武馆弟子、退隐老剑客、披甲悍将等）。为平抑前期 1 级双槽买书税，按招募身价自动预装入门功法：底层苦力（`0 本`）、江湖行当（自带 `1 本` 一重大路货）、成名高手（自带 `1 本` 一重门派上乘 + `1 本` 大路货）。
- **根骨资质（原版星级 Talents，0~3 星）**：先天随机生成，**带星属性数量上限与原版保持一致（每人最多 3 项核心属性带星）**，决定升级时八维摇点下限与上限，保留 BB“招人开盲盒”的乐趣。
  - **洗经伐髓（重塑/冲星规则）**：仅能通过**极稀有的稀世洗髓丹药**，或**极少数顶级孤本内功三重大成时自带的一次洗髓契机**触发。
    - **冲星升级**：对已有星级的属性冲击下一星（`1★ → 2★` 基础成功率 **30%**；`2★ → 3★` 基础成功率 **15%**）。
    - **易筋换星**：若角色已有 3 项带星属性，想给某项 `0★` 属性开星，须指定洗去 1 项原有带星属性来换取目标属性 `0★ → 1★`（基础成功率 **45%**；成功则旧星清空、目标获 `1★`，失败则保留原星不变）。
    - **策略筹备加成**：角色当前的**定力、气血健康度、主修内功重数**与辅助的**护脉丹药**，合计最多可提供 **+15%~20%** 成功率加成。
    - **失败代价**：消耗丹药/契机，必定触发重度内伤**「经脉震荡」**（持续数天，大幅压低气血与内息上限，需靠丹药/名医调养）；冲击 `2★/3★` 失败且无护脉丹时，有 **15%~20%** 概率留下**永久暗疾**（仅可用极稀有的续脉奇药治愈）。
- **特质（Traits）**：原版特质武侠化换名 + 增设契合武侠世界观的先天/后天特质（经脉、悟性癖好、江湖旧疾等）。

## 2. 第二层：全插槽武学培养体系

**核心架构决策：彻底取消原版 Perk 树，改为「升级解锁武学插槽 + 世界获取秘籍装配」。**

### 2.1 升级双收益与 1~11 级插槽解锁表

1. **八维摇点（8 选 3）**：沿用原版，受根骨星级影响。
2. **逐步解锁武学插槽（满级共 7 槽：4 专槽 + 1 双选进阶槽 + 2 后期自由槽）**：老兵等级（12 级起）不再开新槽，仅少量成长属性，防止后期无限膨胀；满级实战底栏主动图标稳定在 6~9 个，不溢出原版技能栏。
3. **全局同类别装配硬上限**：单名角色全身最多同时装备 **2 门内功**（1 主 1 辅）、最多 **2 门轻功**，严禁利用 9/11 级自由槽堆叠 3 门内功或 3 门轻功白嫖面板与回气。

| 解锁等级 | 解锁槽位 | 定位与成长节奏 |
| --- | --- | --- |
| **1 级（天生）** | **主修内功槽 ×1** + **基础外功槽 ×1** | 起步即 2 槽，门派出身自带入门功法、散人买便宜大路货即可上阵 |
| **3 级** | **轻功身法槽 ×1** | 前期渡过新手期，开始分化机动性、闪避与地形适应 |
| **5 级** | **横练 / 杂学槽 ×1** | 中期确立生存路线（轻装卸力 / 铁布衫硬功）或基础战术杂学 |
| **7 级** | **进阶专精槽 ×1（外功 / 横练杂学 二选一）** | 战力大拐点：武痴可修第二外功/副兵器绝学；盾卫、旗手、毒医可补第二本横练/功能杂学，不必苦等 9 级 |
| **9 级** | **自由槽 ×1（可辅修内功）** | **流派分水岭**：可装辅修内功（相克有走火入魔风险），也可补轻功/外功/横练（受全局同类上限约束） |
| **11 级（满级）** | **宗师自由槽 ×1** | 11 级封顶，任意类别皆可装配（受全局同类上限约束），彻底定型核心大哥 |

### 2.2 四大武学类别与原版机制收编

原版 BB 中极有价值的机制型 Perk 全部自然收编为对应类别的武学秘籍，零冗余、全武侠化：

| 武学类别 | 主要读写属性与职责 | 收编的原版核心机制示例 |
| --- | --- | --- |
| **内功心法** | 提升内息上限、定义回气规则（阳刚命中回 / 阴柔闪避回 / 中正稳回 / 邪功击杀回）、轻装护体减伤、定力/气血加成；顶级内功可突破 9 AP 或触发洗髓 | `Recover`（调息为任意内功自带基础能力） |
| **外功套路** | 绑定对应兵器大类（剑/刀/枪/棍/拳掌/暗器/弓弩等），解锁主动招式与门派绝学；部分绝学可突破 9 AP 或提供返 AP/连招机制 | 兵器精通、`Berserk`（收编进狂暴/邪派绝学） |
| **轻功身法** | 加成身法(先攻)、减免地形/高低差移动消耗、脱离控制区(ZoC)或跃迁位移、高身法转招架/避暗；顶级轻功同样可突破 9 AP | `Pathfinder`、`Footwork`、`Rotation`、`Dodge` |
| **横练 / 杂学** | 强化体魄生存流派（轻装卸力 vs 硬功铁布衫）、兵器通用巧劲、毒术、医术、阵法与行军辅助 | `Nimble`（轻装卸力）、`Battle Forged`（横练铁布衫）、`Quick Hands`、`Colossus` 等 |

### 2.3 秘籍品阶、残页与散功覆盖规则

- **四档完整秘籍（消耗品金字塔）**：
  - **大路货**：无门槛，几仗即可大成；城镇书肆/武馆常驻售卖、普通劫匪常见掉落、出身自带，解决前期与替补弟子的“填槽刚需”。
  - **门派上乘**：低~中八维属性门槛；中坚战力与门派核心流派，来自门派交情兑换、委托奖励、门派精英掉落。
  - **绝学**：较高八维/根骨门槛；质变机制、强力控场或短时爆发，来自高危据点、成名高手击杀、拍卖会/鬼市、武林擂台。
  - **江湖孤本**：严苛门槛、全图极稀有；承载**永久突破 9 AP**、顶级洗髓心法与绝世大招，来自武林禁地、顶级奇遇与黑市压轴拍卖。
- **残页合成、藏经阁管理与“残本强修”**：
  - **战团藏经阁（零仓库占格）**：全队获取的 260+ 种武功秘籍与残页自动（或一键）归入角色界面右侧第 3 页签**「藏经阁」**统一管理，不占用战团仓库格位；需要变现时可随时取出至战团仓库在城镇出售。
  - **常规拼合与同阶补缺**：门派上乘 **3 张同名残页**、绝学/孤本 **5 张同名残页**可在藏经阁直接装帧成完整秘籍（支持「一键拼合全部」及 2:1 同品阶闲置残页融会补缺）。
  - **残本强修**：允许在未集齐残页时消耗 1 张残页让角色强行记下残本——最高仅能练至**一重**，且装槽实战存在概率行气不畅散逸内息；日后研读同名完整秘籍可无损补全。
- **秘籍消耗品研习与「已习武学」换槽调息规则**：
  - **消耗品研习（先学会、后配槽）**：武功秘籍为角色消耗品——可在「战团仓库」直接右键给当前角色研读，或在「藏经阁」点击「传授/研习」消耗 1 册，永久加入该角色个人的**「已习武学」**池（同名秘籍不会重复误耗）。
  - **保留重数火候与换槽调息**：在角色「武学修为（原 Perk）」页，仅从该角色个人的「已习武学」池中选装入 7 大插槽；**空槽免费装入**，从已有功法的槽位换装或卸下时，**原功法不销毁，其已练重数与火候 100% 永久保留在角色已习武学库中**，角色仅承受 **1~4 天短暂「散功调息」**（可服护心丹立即化解），既保住珍稀绝学孤本不浪费，又防止每战前零代价无限换克制套路。

### 2.4 功法三重修炼、门槛与走火入魔

- **统一 3 重实质质变（入门 → 小成 → 大成）**：
  - **一重（装入即得）**：立刻获得基础招式或基础被动，上场即用不卡手。
  - **二重（小成）**：数值强化 + 解锁核心机制（内功护体生效、轻功减地形消耗/脱身、外功进阶连招等）。
  - **三重（大成）**：解锁镇派绝招、**突破 9 AP**、或顶级内功自带的**洗髓契机**。
- **火候（修为）获取**：
  - **主来源**：参战结束自动为角色已装备的未满重功法增加火候（实战中使用过该功法招式可享小幅额外加成，不强制玩家在战场上刻意摆拍）。
  - **辅助加速**：城镇武馆请教/营地运功，或服用**凝神/悟道类丹药**直接灌注火候。
- **高阶属性/根骨门槛**：大路货无门槛；绝学/孤本需要满足对应八维属性或根骨星级才允许突破三重大成——使**八维培养、洗经伐髓与顶级秘籍彻底闭环**。
- **功法冲突与走火入魔**：强行在同一角色身上混装属性相克的内功（如至阳配至阴）、残本强修失控、或洗髓失败，会触发内息紊乱、内伤乃至走火入魔。

### 2.5 AP 突破红线与四大类功法数值标尺

#### 行动点 (AP) 边界
- **常人基准**：固定 `9 AP`。
- **常驻 AP 硬封顶 `11 AP`**（绝不允许常驻 `12 AP`）：仅极少数**江湖孤本**（顶级内功或轻功）三重大成提供 `+1 常驻 AP`，全身最多叠加 `+2 AP`（9 → 10 → 11），防止无脑每回合双挥 6 AP 双手重招击穿数值。
- **短时爆发（临时破 12~13 AP）**：仅由条件触发（如邪功/狂暴绝学击杀返 `+3~4 AP`，每回合限 1 次）或高代价主动技（燃血/高耗气 + 冷却，当回合临时 `+2~3 AP`，下回合回气减半或身法下降）提供。
- **招式 AP 定价标尺**：轻灵起手/点刺/暗器/步法 `3 AP`；常规单手外功 `4 AP`；长兵/小范围横扫 `5 AP`；重兵重击/破甲/双连击 `6 AP`；镇派清场绝学 `7~8 AP`。

#### 内功心法标尺（对齐原版 90~130 疲劳 / 每回合回 15）
- **内息上限加成（一重 / 二重 / 三重）**：大路货 `+5 / +10 / +15`；门派上乘 `+10 / +18 / +25`；绝学与孤本 `+15 / +25 / +40`（并附带气血/定力成长）。
- **调息（任意内功一重自带）**：**小调息**（`4 AP` 回已耗内息 25%，当回合招架微降）与**深调息**（`9 AP` 回已耗内息 50%，对应原版 Recover）。
- **四大路数分化**：
  - **中正**：基础每回合回气提高（`+2/+4/+6`），高定力、抗内伤/心魔，可兼容任意辅修内功。
  - **阳刚**：近战命中回复 `3~5` 内息（每回合限次），附带破甲/震劲加成。
  - **阴柔**：敌方近战落空回复 `3~5` 内息；**二重起解锁「真气护体」**（受气血伤时以 1:2 比例扣内息抵消最多 25%~35% 伤害，护住轻装侠客防 5% 爆头）。
  - **邪功**：击杀回复 `15~25` 内息，或以血换气/换临时 AP，滚雪球能力极强但易损气血、受定力反噬。
- **辅修相克规则（9 级后自由槽混修第二门内功）**：`中正` 全兼容；`阳刚` 与 `阴柔`、`正派强阳` 与 `剧烈邪功` 混修时，若定力未达标（且无特定调和孤本），实战有概率触发「内息逆冲」（扣气+轻内伤），强冲三重大成有走火入魔风险。

#### 外功、轻功与横练标尺（防数值膨胀铁律）
- **「重机制、轻面板」与同系被动不累加红线（对齐原版 D100 命中边界）**：
  - **单本三重大成面板上限**（按大路货 / 上乘 / 绝学 / 孤本四档）：外功常驻武艺/射艺封顶 **`+3 / +5 / +7 / +10`**、招架/避暗封顶 **`+2 / +3 / +5 / +6`**，单本额外穿甲率封顶 **`+15%`**（孤本最高 `+20%`）、破甲率封顶 **`+25%`**；内功严禁直接赠送常驻武艺/招架；轻功身法封顶 **`+12 / +18 / +24 / +30`**。
  - **同系多本取最高（`Math.max`）**：同角色兼修多门匹配当前兵器的外功（或多门内功/轻功）时，**主动招式池合并，但常驻攻防面板与穿甲/破甲/命中/身法转防百分比词条一律取最高值，严禁线性累加（`+=`）**；辅修第二内功的常驻内息上限与基础回气按 **`50%` 折算**，确保 11 级毕业大哥武艺稳定在 `95~105` 原版黄金区间，保住先天星级与洗经伐髓价值。
- **外功内息消耗**：兵器自带朴素平招 `8~12`；外功常规招 `12~18`；范围/连击强招 `20~28`；绝学大招 `30~45`。
- **轻功身法**：一重加身法并减免地形/高低差移动消耗；二重按当前有效身法比例转化招架/避暗（常规上限 `15%~18%`、孤本最高 `20%`，重甲压身法则吃不到，天然绑定轻装流）；三重解锁主动身法技（无视 ZoC 脱身 / 短距纵跃 / 换位），孤本轻功三重提供 `+1 常驻 AP` 或每回合首步免费。
- **横练 / 杂学生存双轨对称与战术胶水**：
  - **轻装卸力系**（对应原版 Nimble）：头身衣甲总负重 ≤ 15 时，气血实伤减免最高达 `40%~55%`（超重衰减）；与内功「真气护体」同时生效时，**气血实伤总减免乘算硬封顶 `60%`**，严防布衣肉度反超重甲。
  - **横练铁布衫系**（对应原版 Battle Forged + Brawny + Steel Brow）：按护甲厚度减免损甲并提供气血/抗外伤门槛，同时内置**「披甲行气」（减免头身甲 `25%~30%` 的内息与身法负重惩罚，对冲“疲劳=内息合一”对重甲的双倍压制）**与**「铜头铁额」（大成减免/免疫爆头额外暴击倍率）**；高阶横练可进一步提供主动硬抗架势（对标 `Indomitable`）。
  - **团队生态位与炮灰兜底拼图**：后续扩充秘籍池时严禁纯数值换皮，须覆盖低星散人兜底（落空叠命中 `Fast Adaptation`、濒死锁血 `Nine Lives`、围攻补正 `Backstabber`）、阵线抗围（免围攻扣防 `Underdog`、嘲讽 `Taunt`）与军心中枢（群体稳战意 `Rally`）；前中期 `ExpNeeded` 曲线对齐 **2/4/6/8 偶数级**升重突破节奏。

## 3. 第三层：战斗、兵甲、伤养与 12 人江湖梯队

### 3.1 战斗核心原则

- **克制维度，顺应回合制**：**不新增独立架势条，不做硬性“剪刀石头布”招式克制表，不做回合外弹窗反应交互**。
- **状态效果承载博弈**：通过清晰的战斗状态（**破绽、失衡、蓄势、反击架势、点穴封气、内伤、中毒、烟幕**等）呈现拆招、破防与打断。
- **敌我同源（所见即所得）**：敌方高手同样按插槽规则挂载内功/外功/轻功/横练；玩家在战场上见到对手使出某门强力武学，击败他就有机会爆出对应秘籍或残页。

### 3.2 兵甲分工与轻重装自然克制

- **兵器 vs 外功（含成对拳套、单手孤锋与号令解绑）**：
  - **兵器**决定基础伤害、破甲率、伤甲率、射程、负重，仅自带 1~2 个朴素平招。
  - **拳掌 / 指爪成对武器化（`Fist` 大类）**：不做主手留空（`null`）的裸手高伤技，统一采用**成对占满主副手槽（4 AP 出招）的缠手布 → 精铁指虎/护腕 → 玄铁拳套/传世护手**，杜绝单手拳套配大盾的违和感，完整接入铁匠铺经济与红装词条成长；战术上对标钝器（Mace）赛道，主打**高穿甲内劲、封脉内伤、点穴震慑与夺刃缴械**，专克重甲横练。
  - **单手空副手 vs 藤牌守线**：单手刀剑空副手保留原版双握（`+25%` 伤），并由杂学《孤锋诀》（对标 `Duelist`）补足空副手穿甲（全身总额外穿甲硬封顶 `+25%`）；盾牌映射为**藤牌 / 铁圆盾**，专服务于前排护卫。
  - **军心号令解绑武器槽**：「振奋军心（`Rally`）+ 定力光环」收编为统帅类杂学秘籍（如《聚义令》），不再强迫掌门/大师兄放弃本命兵器去扛双手大旗。
  - **外功秘籍**绑定兵器大类，手持对应兵器时解锁整套门派招式与绝学。
  - **名器 / 神兵（原版红装体系）**：极品数值之外附带降内息消耗、高穿甲或特殊词条，成为秘籍之外的**第二条终极追求线**。
- **双轨生存与自然克制**（由“内力=疲劳合一”与原版护甲机制自然涌现）：
  - **轻装侠客（布衣 / 劲装 / 软甲）**：负重极低 → 保留高额内息上限与身法 → 高频施展武学、轻功满场游斗，依靠**内功护体（耗内息抵伤）+ 轻装卸力秘籍 + 高招架**防暴毙。
  - **重装 / 横练（铁甲 / 官兵甲 / 铁布衫金钟罩）**：压低内息上限与身法 → 难以施展高耗气轻功连招，但极难破防，靠低耗气重兵稳扎稳打。
  - **自然克制闭环**：高身法/多 AP 轻装剑客切后排 → 怕长枪/控制/阵型卡位；重甲硬功扛物理 → 怕破甲重兵、震劲内伤与毒功；高招架轻装 → 怕暗器、毒烟与高命中/范围绝学。

### 3.3 双线伤养体系

复用并扩展原版“临时伤 + 永久残废”框架：
- **外伤**：物理伤害打穿气血阈值触发（骨折、裂创等），靠金疮药与常规医馆休养恢复。
- **内伤 / 走火入魔**：由高阶内劲重创、洗经伐髓失败或相克内功冲突触发，压制内息上限与回气速度，常规外伤药无效，需依赖**专用丹药、名医或闭关调息**恢复。

### 3.4 队伍规模与梯队生态

- **沿用原版规模**：最多 **12 人上场、20 人花名册**。
- **无固定领队绑定**：任何人皆可战死，任何人皆可吃资源成长为队内王牌。
- **自然形成的江湖梯队**：12 人规模与秘籍品阶金字塔天然匹配——**2~4 名核心大哥**吃孤本/绝学/AP 突破/洗髓，**4~6 名中坚好手**配门派上乘与精良兵甲，**外围/替补弟子**用大路货填槽扛线与轮换。

## 7. 技术架构与引擎边界备忘（已核实约束）

以下为前期技术调研中已核实的硬约束，后续细化与编码时严格遵守：

1. **核心依赖**：`Modern Hooks` + `MSU`（不再强制引入 `Dynamic Perks Framework` 和 `Nested Tooltips`），要求原版**全部 5 个 DLC**（工艺系统依赖野兽与探索，随从/竞技场依赖烈焰沙漠）。声明与 `mod_legends`、`mod_reforged` 冲突。
2. **势力 ID 红线**：原版引擎战斗内势力 ID ≥ 64 会破坏控制区与视野，创建真势力时必须校验并打日志监控。
3. **中文显示方案**：HTML 界面支持中文；原版引擎大地图位图字体不支持中文，基准运行环境采用 **汉化包 + bb-launcher**（同时预留地图名称拼音兜底开关，并保持对 Modern Engine 的兼容）。
4. **地图尺寸上限**：原版引擎世界地图上限约 `140 × 170`，前期沿用默认随机生成尺寸。
5. **命名与美术合规**：面向公开发布时，门派与武学名称使用历史通用名（少林、武当、华山、峨眉、唐门、丐帮等）或纯原创名，规避受版权保护的小说专有名；美术以暗黑明末写实基调为主，后期分批替换。
