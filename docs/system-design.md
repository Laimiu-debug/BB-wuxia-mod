# 《战场兄弟》武侠 Mod 核心系统总设计

> **文档地位**：本项目当前的**唯一设计真相源（Single Source of Truth）**。  
> 早期探索稿（独立内力条、DPF 动态天赋树、架势条、后台自治药镖等旧口径）均已归档至 `docs/archive/`，仅供历史参考，不再作为现行规格。

---

## 0. 设计总纲与核心原则

1. **以人物培养为绝对核心，自底向上建构**：先锁死 BB 原版人物属性骨架，再围绕属性长出“插槽秘籍培养 → 战斗兵甲 → 江湖大世界与经济”四层闭环，绝不堆砌与核心循环脱节的悬浮系统。
2. **顺应 BB 引擎底层，不做反引擎魔改**：保留 BB 最经久不衰的八维数学、装备负重博弈、12 人群战与高风险高回报铁人感，将所有开发精力聚焦在**武学构筑多样性、秘籍/洗髓追逐感与江湖内容厚度**。
3. **无固定主角，谁都可以是主角**：沿用 BB 经典幕后掌门/领队视角，没有强制不可死亡的主角单位，人人皆可凭机缘与培养成为大哥，人人也皆可战死沙场。
4. **轻量稳健的技术底座**：因彻底取消传统 Perk 树，**不再强依赖 DPF 与 Nested Tooltips**；底层框架收敛为 **Modern Hooks + MSU**（要求全 DLC 以复用工艺、随从、竞技场等原版模块），数据结构与存档完全自主可控。

## 1. 第一层：人物属性底盘

核心思路：**不动 BB 原版核心八维的底层数学公式**，通过武侠化语义重塑与后续系统（武学、装备、丹药）读写这些数值。

### 1.1 核心八维（升级时照旧 8 选 3）

| 原版八维 | 武侠对应（暂定名） | 底层职责与关键联动 |
| --- | --- | --- |
| 生命值 (HP) | **气血** | 承受实伤、决定外伤触发阈值 |
| 疲劳值 (Fatigue) | **内息 / 内力** | **内力与疲劳合一（单资源池）**；移动、出招、内功护体均消耗此池；受衣甲负重直接压制上限 |
| 意志 (Resolve) | **定力 / 心志** | 战意检定、抗恐惧/震慑/心魔、影响高阶内功修炼与冲突抗性 |
| 先攻 (Initiative) | **身法** | 回合出手顺序；与轻功、闪避、先手压制深度联动；实时受负重与当前已耗内息影响 |
| 近战技能 (MAtk) | **武艺** | 近身出招命中率 |
| 远程技能 (RAtk) | **射艺 / 暗器** | 弓弩、飞镖、暗器命中率 |
| 近战防御 (MDef) | **招架** | 近身闪避与拆招防御 |
| 远程防御 (RDef) | **避暗** | 躲避箭矢与暗器 |

### 1.2 结构与战斗衍生属性

- **行动点 (AP)**：常人默认固定 **9 点**；**不再写死，但仅能通过特定武功秘籍（高阶/高重功法）突破**。数值上严控 9 → 10 → 11（及带代价的短时爆发）的质变阶梯，防止单回合无脑双大招击穿平衡。
- **头甲 / 身甲**：沿用原版护甲与穿甲底层机制，替换为武侠冠帽与衣甲，支撑“轻装 vs 重甲”双轨生存。
- **战意（原版士气 Morale）**：沿用原版 5 档状态（高昂 → 稳定 → 动摇 → 崩溃 → 溃逃），由定力驱动。
- **视野 (Vision) & 控制区 (ZoC)**：沿用原版底层机制。
- **移动消耗（地形、高低差、脱离 ZoC）**：**由轻功系统全面接管与改写**。

### 1.3 先天底盘与“洗经伐髓”

- **出身（原版 Background）**：江湖行当与门派师承（决定初始八维区间、初始特质池、雇佣与维持成本、自带基础入门秘籍）。
- **根骨资质（原版星级 Talents，0~3 星）**：先天随机生成，决定升级时八维摇点下限与上限，保留 BB“招人开盲盒”的乐趣。
  - **洗经伐髓（重塑根骨）**：仅能通过**极稀有的顶级内功大成或稀世丹药**触发，可改变/提升角色的根骨星级。
  - **稀缺与概率原则**：洗经伐髓**带有失败概率，不能轻易成功**；失败会消耗珍稀丹药/机缘，并触发**经脉震荡/内伤**（极低概率留下永久暗疾），让“逆天改命”既有史诗感又有真实代价。
- **特质（Traits）**：原版特质武侠化换名 + 增设契合武侠世界观的先天/后天特质（经脉、悟性癖好、江湖旧疾等）。

## 2. 第二层：全插槽武学培养体系

**核心架构决策：彻底取消原版 Perk 树，改为「升级解锁武学插槽 + 世界获取秘籍装配」。**

### 2.1 升级双收益

1. **八维摇点（8 选 3）**：沿用原版，受根骨星级影响。
2. **解锁武学插槽**：随角色等级提升逐步开放插槽（1 级起步带初始槽，满级拥有完整构筑槽位）。玩家通过世界探索、打架、奇遇、门派兑换、拍卖获取秘籍并装入插槽，打造风格迥异的核心大哥。

### 2.2 四大武学类别与原版机制收编

原版 BB 中极有价值的机制型 Perk 全部自然收编为对应类别的武学秘籍，零冗余、全武侠化：

| 武学类别 | 主要读写属性与职责 | 收编的原版核心机制示例 |
| --- | --- | --- |
| **内功心法** | 提升内息上限、定义回气规则（阳刚命中回 / 阴柔闪避回 / 中正稳回 / 邪功击杀回）、轻装护体减伤、定力/气血加成；顶级内功可突破 9 AP 或触发洗髓 | `Recover`（调息为任意内功自带基础能力） |
| **外功套路** | 绑定对应兵器大类（剑/刀/枪/棍/拳掌/暗器/弓弩等），解锁主动招式与门派绝学；部分绝学可突破 9 AP 或提供返 AP/连招机制 | 兵器精通、`Berserk`（收编进狂暴/邪派绝学） |
| **轻功身法** | 加成身法(先攻)、减免地形/高低差移动消耗、脱离控制区(ZoC)或跃迁位移、高身法转招架/避暗；顶级轻功同样可突破 9 AP | `Pathfinder`、`Footwork`、`Rotation`、`Dodge` |
| **横练 / 杂学** | 强化体魄生存流派（轻装卸力 vs 硬功铁布衫）、兵器通用巧劲、毒术、医术、阵法与行军辅助 | `Nimble`（轻装卸力）、`Battle Forged`（横练铁布衫）、`Quick Hands`、`Colossus` 等 |

### 2.3 秘籍品阶、消耗与覆盖规则

- **秘籍为消耗品，分品阶形成金字塔**：
  - **残页**：多张拼合完整秘籍（或作为残本冒险强修，具体细则待定）。
  - **大路货**：基础入门功法，城镇书肆/武馆常驻售卖、普通劫匪常见掉落、出身自带，解决前期与替补弟子的“填槽刚需”。
  - **门派上乘**：中坚战力核心构筑，来自门派交情兑换、委托奖励、门派精英掉落。
  - **绝学**：质变级武学，来自高危据点、成名高手击杀、拍卖会/鬼市、武林擂台。
  - **江湖孤本**：最稀缺的顶级秘籍（含突破 9 AP、绝世心法等），来自武林禁地、顶级奇遇与压轴拍卖。
- **插槽允许覆盖替换（散功重修），但有代价**：允许用新秘籍顶替旧插槽里的功法（避免前期“仓鼠病”不敢装大路货），但**旧功法随之销毁**，且角色承受散功虚弱/重修代价。

### 2.4 修炼重数、门槛与走火入魔

- **修炼重数**：秘籍装入插槽即获 1 重（立即可用，不卡手）；随实战历练/运功提升重数，高重/大成才解锁绝招、AP 突破或洗髓等质变效果。
- **高阶属性/根骨门槛**：大路货与常规武学无门槛；顶级绝学/孤本要求角色达到对应八维属性或根骨星级门槛——使**八维培养、洗经伐髓与顶级秘籍彻底闭环**。
- **功法冲突与走火入魔**：强行在同一角色身上混装属性相克的内功（如至阳配至阴），或突破/洗髓失败，会触发内息紊乱、内伤乃至走火入魔。

## 3. 第三层：战斗、兵甲、伤养与 12 人江湖梯队

### 3.1 战斗核心原则

- **克制维度，顺应回合制**：**不新增独立架势条，不做硬性“剪刀石头布”招式克制表，不做回合外弹窗反应交互**。
- **状态效果承载博弈**：通过清晰的战斗状态（**破绽、失衡、蓄势、反击架势、点穴封气、内伤、中毒、烟幕**等）呈现拆招、破防与打断。
- **敌我同源（所见即所得）**：敌方高手同样按插槽规则挂载内功/外功/轻功/横练；玩家在战场上见到对手使出某门强力武学，击败他就有机会爆出对应秘籍或残页。

### 3.2 兵甲分工与轻重装自然克制

- **兵器 vs 外功**：
  - **兵器**决定基础伤害、破甲率、伤甲率、射程、负重，仅自带 1~2 个朴素平招。
  - **外功秘籍**绑定兵器大类，手持对应兵器（或空手配拳掌）时解锁整套门派招式与绝学。
  - **名器 / 神兵（原版红装体系）**：极品数值之外附带降内息消耗、高穿甲或特殊词条，成为秘籍之外的**第二条终极追求线**。
- **双轨生存与自然克制**（由“内力=疲劳合一”与原版护甲机制自然涌现）：
  - **轻装侠客（布衣 / 劲装 / 软甲）**：负重极低 → 保留高额内息上限与身法 → 高频施展武学、轻功满场游斗，依靠**内功护体（耗内息抵伤）+ 轻装卸力秘籍 + 高招架**防暴毙。
  - **重装 / 横练（铁甲 / 官兵甲 / 铁布衫金钟罩）**：压低内息上限与身法 → 难以施展高耗气轻功连招，但极难破防，靠低耗气重兵稳扎稳打。
  - **自然克制闭环**：高身法/多 AP 轻装剑客切后排 → 怕长枪/控制/阵型卡位；重甲硬功扛物理 → 怕破甲重兵、震劲内伤与毒功；高招架轻装 → 怕暗器、毒烟与高命中/范围绝学。

### 3.3 双线伤养体系

复用并扩展原版“临时伤 + 永久残废”框架：
- **外伤**：物理伤害打穿气血阈值触发（骨折、裂创等），靠金疮药与常规医馆休养恢复。
- **内伤 / 走火入魔**：由高阶内劲重创、洗经伐髓失败或相克内功冲突触发，压制内息上限与回气速度，常规外伤药无效，需依赖**专用丹药、名医或闭关调息**恢复。

### 3.4 队伍规模与梯队生态

- **沿用原版规模**：最多 **12 人上场、20 人花名册**。
- **无固定领队绑定**：任何人皆可战死，任何人皆可吃资源成长为队内王牌。
- **自然形成的江湖梯队**：12 人规模与秘籍品阶金字塔天然匹配——**2~4 名核心大哥**吃孤本/绝学/AP 突破/洗髓，**4~6 名中坚好手**配门派上乘与精良兵甲，**外围/替补弟子**用大路货填槽扛线与轮换。

## 4. 第四层：务实增强型大世界与经济闭环

### 4.1 全面武侠化与地图策略

- **世界观全面替换**：无中世纪兽人、亡灵、地精，全部替换为武侠生态（绿林山寨、重装战帮、奇门伏兵、古墓机关与邪祟、各派武人、官军世家、山泽异兽）。
- **地图务实分步**：先复用 BB 原版随机世界生成 + 全面中式命名 + 按地形绑定门派与据点分布；“固定神州大区布局”作为远期可选项。
- **大世界交互边界**：采用**务实增强型 BB 世界**——基于原版商队、巡逻队、城镇状况与势力行动，重点做深**拍卖会/鬼市、门派交情与寻仇、城中擂台、奇遇事件链、残页合成与武林禁地**，不做重度全图后台 NPC 实时接单/物品跨队追踪模拟。

### 4.2 核心养成资源分层投放

| 资源品阶 | 主要产出途径 | 驱动的玩家行为 |
| --- | --- | --- |
| **大路货秘籍** | 城镇书肆/武馆常驻售卖、普通劫匪/散人掉落、出身自带 | 12 人队伍前期与替补的“填槽刚需”，有钱即可兜底 |
| **残页 & 门派上乘** | 门派交情/拜师换取、江湖委托（押镖/剿匪/悬赏）、门派精英掉落 | 跑委托、经营门派交情、针对性挑战门派强敌 |
| **绝学 & 珍稀丹药** | 高危据点清剿、成名高手击杀、**拍卖会 / 鬼市竞拍**、城中擂台大会 | 维持中后期赚钱动力、挑战高危据点与高手 |
| **江湖孤本 & 洗髓奇药** | **武林禁地（传奇秘境）**、顶级奇遇事件链、黑市压轴拍品、**百工顶级炼丹（异兽奇材）** | 大后期终极探索、猎杀异兽采材、攒巨款抢拍 |

### 4.3 经济与百工炼丹闭环

- **支出端**：12 人酬银与口粮 + 外伤/内伤医治药费 + 兵甲修缮添置 + 买秘籍、竞拍孤本、采买炼丹奇材。
- **收入端**：江湖委托 + 战利品与多余残页转卖 + 城中擂台/赌斗彩头 + 商货贸易。
- **百工与炼丹**（复用原版 Crafting 工艺框架）：猎杀山泽异兽与秘境强敌产出奇材 → 合成**疗内伤丹药、战前药散、兵器涂毒、衣甲附具、稀世洗髓丹**，赋予野兽/异兽完整的生态价值。

### 4.4 势力架构（严守 64 势力 ID 上限）

- **真势力（复用原版 Faction，总数严控在安全红线内）**：市镇集市、朝廷/世家大族（替原版贵族）、少数核心江湖阵营与敌对势力（绿林、边地、古墓、异兽等），直接复用城镇归属、巡逻队、关系值、委托与后期危机。
- **门派与师承（轻量标签化，不硬占 Faction ID）**：依托城镇武馆、山川据点或游方传人承载，各自维护独立的**门派交情**。交好可拜师换本派秘籍、招募高阶弟子；交恶则触发道路上的**门派寻仇队**。未来扩充至十余个门派也不会撞穿引擎 64 上限。

### 4.5 后期考验：武林大势与终极挑战

- **江湖志向（替代原版 Ambitions）**：从站稳脚跟、习得首门绝学，一路递进至声震江湖与挑战禁地。
- **武林大势（替代原版后期危机）**：正邪大战/魔教东来、朝廷与世家纷争、山寨/边地联军犯境、古墓秘境异变。
- **终极挑战（替代原版传奇地点）**：多处高难度**武林禁地** + **天下武林大会（终极擂台）**，检验成型 12 人插槽队伍的极限构筑与配合。

## 5. 技术架构与引擎边界备忘（已核实约束）

以下为前期技术调研中已核实的硬约束，后续细化与编码时严格遵守：

1. **核心依赖**：`Modern Hooks` + `MSU`（不再强制引入 `Dynamic Perks Framework` 和 `Nested Tooltips`），要求原版**全部 5 个 DLC**（工艺系统依赖野兽与探索，随从/竞技场依赖烈焰沙漠）。声明与 `mod_legends`、`mod_reforged` 冲突。
2. **势力 ID 红线**：原版引擎战斗内势力 ID ≥ 64 会破坏控制区与视野，创建真势力时必须校验并打日志监控。
3. **中文显示方案**：HTML 界面支持中文；原版引擎大地图位图字体不支持中文，基准运行环境采用 **汉化包 + bb-launcher**（同时预留地图名称拼音兜底开关，并保持对 Modern Engine 的兼容）。
4. **地图尺寸上限**：原版引擎世界地图上限约 `140 × 170`，前期沿用默认随机生成尺寸。
5. **命名与美术合规**：面向公开发布时，门派与武学名称使用历史通用名（少林、武当、华山、峨眉、唐门、丐帮等）或纯原创名，规避受版权保护的小说专有名；美术以暗黑明末写实基调为主，后期分批替换。

## 6. 待下一轮逐章细化的设计细则

1. **插槽解锁表与槽位结构**：1~11 级具体在哪些等级开槽？满级总槽位数及各类槽位（内功/外功/轻功/横练杂学）的配比。
