# 项目讨论纪要（聊天整理）

整理自 Cursor Project「BB 武侠mod」截至 2026-11-18 的对话。只记结论与待定项，不重复百科正文。

## 已确认前提

- 基于原版（不依赖 Legends）；用户有 AI 开发 mod 经验；美术试用 AI 生成。
- 要门派弟子 + 按武器的技能 + 大量外围系统；地图也想改。
- 代码仓库：https://github.com/Laimiu-debug/BB-wuxia-mod （当前以设计 HTML 为主）。
- 本地路径：`G:\CODE\BB wuxia mod`（云端需本机 `agent worker start` 才能直接读写）。

## 架构讨论要点

- **武器层 + 门派层**：武器提供通用基础招式；门派提供心法与绑定武器类型的独门武学。两者叠加，不二选一。
- **Perk 大改**：不必自写 perk UI。倾向 Dynamic Perks Framework（另需 Nested Tooltips + Modern Hooks + MSU，共 4 依赖）。按背景/门派拼不同树；秘籍拜师可运行时加组。敌人不走 perk，要单独挂 skill。
- **内力**：聊天早期方案写「独立资源」；用户大纲与仓库百科已定为 **疲劳换皮成内力**。以百科「已选方向」为准，设计方案第 2 节待改。
- **架势条**：大纲要做；界面条位紧张。评审建议第一阶段先用状态效果做简化破绽，不单列架势条（待用户拍板）。
- **地图**：换皮成本中等；改世界生成与固定神州方位成本高、易出存档问题。建议后期；原版引擎地图上限约 140×170，中文大地图名需 bb-launcher / Modern Engine / 拼音。
- **世界去留**：大纲与百科映射等价于 **全面替换原版中世纪皮**；势力建议套在原版势力类上以复用契约。

## 用户六模块大纲摘要

1. **定位**：不做独立游戏，深耕 BB 大型 mod；美术暗黑明末写实（《绣春刀》《镖人》）；音乐偏埙/尺八/琵琶/战鼓。
2. **战斗**：内力替疲劳 + 调息；架势替部分护甲，破绽重伤；剑刀枪棒暗器差异化；轻功无视 ZOC；简易招式克制。
3. **养成**：出身改编；武学树分内功/外功/轻功/杂学；秘籍残页与拜师；兵器卷刃、涂毒、丹药、走火入魔等。
4. **江湖生态**：门派势力、朝廷、声望恩怨、奇遇、市井、镖局等。
5. **起源矩阵**：多个江湖开局（镖局、门派、独行等）。
6. **落地路线**：分阶段，先可玩核心再扩系统与地图。

门派原型讨论中包括禅宗、玄门、剑派、世家、唐门类暗器、毒派、丐帮、血刀/密宗、魔教、医道等；公开发布时金庸/古龙专名需原创化。

## 技术注意（讨论中核实）

- DPF 改角色存档格式 → 必须新开档。
- 炼丹/工艺与幕僚/随从分别依赖「野兽与探索」「烈焰沙漠」等 → 实际宜要求全部 DLC。
- 原版无女性角色素材；医女/峨眉类要整套新画。
- 战斗内势力 ID 到 64 会出错。

## 仍待拍板（摘自评审）

1. 第一阶段是否不做独立架势条、只用状态效果做破绽。
2. 第一个可玩切片：威远镖局护撤 vs 名山剑派。
3. 中文运行环境（汉化包 + bb-launcher / Modern Engine / 拼音）。
4. Windows 实机测试环境是否具备。
