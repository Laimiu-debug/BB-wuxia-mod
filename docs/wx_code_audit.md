# 山海武侠 Mod 代码审查与实机验证

2026 年 11 月 23 日，Windows 版《战场兄弟》1.5.2.3，Mod 0.8.7。审查对象是当前工作区打入游戏包的代码和资源。测试使用本机游戏的独立副本、Modern Hooks 和专用战役存档。

## 已修复的问题

| 玩家操作 | 修复内容 | 验证方式 |
| --- | --- | --- |
| 从藏经阁研习并装配 | 原入口读取不存在的配置，导致角色界面报错。研习和换装现在共用槽位、等级、同类上限及散功校验。过期确认保留书籍，同槽补全残本保留火候。 | 实际角色界面调用成功。越界和过期确认均保留库存，确认换装只扣一本，原功法保留。 |
| 防御、回气与爆发 | 铁布衫、寒冰和易筋三种架势改用浮点运算。轻装卸力叠加真气护体时，承伤倍率下限为 0.40，到下限后不再扣气。临时 AP 在多次返还后仍以 13 为上限。 | 引擎检查单项倍率、叠加下限、内息扣除和回合末复位。 |
| 招式收益与内伤 | 饕餮只从相邻的活体敌人吸取实际可用的内息。破阵杀伐气在生效期间阻止负向士气检定。金针、易筋和山门治疗调用统一的临时内伤治疗逻辑，保留永久经脉伤痕。 | 测试已耗尽目标、盟友和亡灵。在实际战斗中验证士气保护、金针对自己与邻接同伴的选取，以及治疗后的永久伤痕。 |
| 存档与常驻面板 | 补齐旧数据中的角色天赋与升级掷点数组时保留已有值。袖手暗器各重射艺调整为 +3、+4、+5，符合横练杂学上限。 | 引擎连续两次补齐残缺数组，并逐重检查所有横练杂学的常驻攻防。 |
| 战斗技能栏 | 超过九个技能时分页显示，保留原技能快捷键和选取状态。 | 游戏原生界面组件显示 21 个技能，三页分别为 9、9、3 个。实战中同时核对了后端返回的技能 ID、AP 与内息。 |
| 掉落、音效和地图加载 | 七个远程招式改用游戏中存在的音效，火器增加本体音效回退。古墓事件改发可实例化的战利品。附属地点的预加载目录改为游戏实际目录。 | 对照游戏与 Mod 资源清单，运行奇遇结果页，并实际生成地图。 |
| 开发包冒烟测试 | 原脚本可能在看到主菜单时，把尚未输出自检结果的开发包判为成功。现在读取待测 ZIP 的构建标志，同时检查核心、菜单和开发包自检结果。 | 用缺失核心、缺失菜单、缺失自检及完整日志分别验证判定。 |

## 验证范围

| 对象 | 本轮验证 |
| --- | --- |
| 源码与成包 | 游戏 Squirrel VM 逐个编译 933 个脚本。6 个界面脚本通过 ES3 语法解析。正式 ZIP 的 3,941 个条目逐一与工作区比对并通过 CRC 校验。 |
| 注册与规则 | 开发包冷启动 142 项引擎自检全部通过。覆盖 276 本秘籍、171 个主动招式、丹方、锻造、战术 AI、山海装备与存档迁移等模块。171 个主动招式均在引擎中实例化。 |
| 七种起源 | 每种起源单独启动一次新战役，均生成 22 座城镇。逐人读取角色界面和七槽数据，七次开局均通过。 |
| 二进制存档 | 读取修复前生成的专用存档，换装后另存，重新启动正式包再读。五名队员、七个槽位、三本已学秘籍、新装配的内功和藏经阁扣书结果均正确。 |
| 事件 | 在隔离战役中执行全部 82 个奇遇的 359 个画面，调用当时可用的 505 个选项，检查返回的目标画面，异常和无效跳转均为零。 |
| 战斗 | 16 队擂台生成 15 场签表，一场 5 对 5 的 AI 对战打至胜负并写回结果。另以玩家队报名入场，验证原生战斗栏和治疗选取。 |
| 资源 | 核对运行时代码中 866 个不同的静态图像和音频路径，全部可在游戏和 Mod 资源中解析。动态拼接的资源另由引擎自检与实际运行覆盖。 |
| 正式包 | 关闭开发自检，使用本机现有的五个配套 Mod 冷启动并进入主菜单。正常启动和专用存档复读两次运行的错误及严重错误日志均为零。 |

实际战役使用固定地图种子。随机装备的全部词条组合、每招对每种敌人的结算、长期战役推进、各 DLC 子集、玩家自用旧档和第三方 Mod 组合仍缺少穷举验证。
