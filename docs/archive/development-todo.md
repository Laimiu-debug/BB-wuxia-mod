# 武侠 Mod 开发待办清单

配套[开发路线](development-roadmap.md)。目前处于规划阶段。每项在目标游戏环境达到所列结果后勾选，网页推演和设计资料可作为核对依据。

## 阶段 1 · 游戏接入与主菜单

- [ ] **1.1** 记录一套能复现的 Windows 游戏版本、DLC、中文字体与启动方式，确定首轮框架组合及其实际依赖。
- [ ] **1.2** 建立最小 Mod 包和构建入口，能安装、冷启动、看到加载日志、开新局，并保存和重新载入一份测试战役。
- [ ] **1.3** 核实主菜单、起源选择、加载与引擎启动画面的可修改范围，在武侠主菜单草版上接回新局、读档、设置和退出。
- [ ] **1.4** 在目标环境核对临时题签、中文字体、缩放与菜单往返，留下首次启动和返回主菜单两张可对照的画面。

## 阶段 2 · 战役数据与存档

- [ ] **2.1** 给人物、门派、势力、功法、物品与差事稳定编号。门派与武学的共用定义单独维护，每局存储各人师承和修习结果，名字与素材可以替换。
- [ ] **2.2** 用一个样例角色分别记录出身、禀性、师承、势力关系、同行承诺、所学与所持，验证一人可同时拥有不同性质的关系。
- [ ] **2.3** 让游戏规则保存事实，界面读取事实并提交操作。记录存档格式版本，保留一份可用于验证后续字段迁移的测试档。
- [ ] **2.4** 用两份测试战役验证存读与单局隔离。改变样例角色的归属后再读档，物品、已学武艺与已兑现承诺都能复原，结算结果只生效一次。

## 阶段 3 · 人物、混编与习武

- [ ] **3.1** 建立首轮师承与势力样本，给每家明确能教什么、在意什么、谁可引荐。用一个起源带出三名来历不同的同行者。
- [ ] **3.2** 做出相遇、招募、约定、离队与再次同行的最小流程。玩家能让不同势力出身的人为同一件事并肩。
- [ ] **3.3** 接通向师父求教、研读已有秘籍、试用与选择深修方向。同门弟子和跨派求学者都能形成自己的所学记录。
- [ ] **3.4** 接上起源页、侠客名册与修习簿的简版交互。从同一开局分别选择两条修习路线，读档后仍能分辨两支队伍。

## 阶段 4 · 交手、敌方行为与实战成长

- [ ] **4.1** 让内力承接疲劳，明确行动、用气、回气、装备负重和气竭后可选的基础动作，敌我按对应规则行动。
- [ ] **4.2** 用少数兵器、内功、外功与身法打通起手、应对、中断和收势。至少做出一套围绕主攻、一套依靠换手的配合。
- [ ] **4.3** 给原型对手明确目标、可见征兆与收手条件。让敌方在同一场会武里能应对两支队伍。
- [ ] **4.4** 让战斗结果回写本人历练，接通实做、回师验证和进阶。战斗 HUD 与战后页能说明每个人为何有这次修习机会。

## 阶段 5 · 势力与第一段完整战役

- [ ] **5.1** 接通委托、物品归属和势力行动，用一票药镖跑到送达、失镖或别队承运后的最终去向。
- [ ] **5.2** 将酬银、补给、伤养、见证人和地方消息接到同一件事，跑通一次用现有药材配药。读档后可沿原货追查，失镖后仍有一项可承担的差事。
- [ ] **5.3** 让办事结果改变势力交情、求教引荐或下次招募机会，从新开局走完两趟彼此有因果的差事。
- [ ] **5.4** 用同一开局、同一册剑谱和同一组对手试玩两条路线，再比较同一位名门剑客与原队老镖师的价值，将过强的通用选择带回阶段 3–4 调整。

## 阶段 6 · 自有 UI 完整接入

- [ ] **6.1** 定稿全局中文字体层级、导航、焦点、提示与窗口操作，完成主菜单、新局、起源、读档和设置的正式布局。
- [ ] **6.2** 完成招募、队伍与侠客页、武学与修习簿，能从队伍的打法查到个人的师承、职责和可学机会。
- [ ] **6.3** 完成战斗 HUD、招式说明、敌方意图与战后结算，核对行动预览、实际结果和成长记录。
- [ ] **6.4** 完成舆图、城镇、势力人情、委托日志、行囊、伤养及已有百工操作。用真实战役查完整导航、返回、存读和不同分辨率下的中文显示。

## 阶段 7 · 分批替换美术与内容

- [ ] **7.1** 用一组正式题图、题签、窗口与武学图标替换临时素材，在主菜单、名册和战场三处核对风格与可读性。
- [ ] **7.2** 完成首名侠客和长短两件兵器的整套样稿，检查人物分层、装备锚点、持械与背包图、受伤及倒地表现，再扩到首批同伴与敌手。
- [ ] **7.3** 替换一处战场和一处城镇，再扩地域地形、据点、旗帜、大地图队伍及事件插画，验证同一委托仍可到达和交割。
- [ ] **7.4** 用第二批门派内容验证同一套规则可复用。每批交付师承、可学功法、对手打法、关联差事和对应美术，并用上一批的战役存档回查。

## 阶段 8 · 长战役与发布准备

- [ ] **8.1** 按已验证的玩法扩不同起源与地区，逐批加入名器追索、百工、异兽、擂会、江湖风波及隐退或其他单局结局。
- [ ] **8.2** 做同开局与多开局试玩，记录招募、换人、深修和面对同一强敌时的选择理由，复查是否出现普遍最优的个人或功法。
- [ ] **8.3** 长战役验证势力变化、离队人物、名器归属、经济恢复、事件是否重复，以及地图和战斗表现。
- [ ] **8.4** 用候选包走完首次安装、启用依赖、开局、读档与版本升级，整理安装说明、兼容范围、存档要求和已知问题。
